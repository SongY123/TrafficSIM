# 偶发事故场景

该场景使用视野清晰、路面正常的城市或园区道路，不包含雨雪、雾、积水、复杂交叉口和特殊外界障碍。

道路为单向双车道，前方包含轻微弯道，并在事故点前约40米处设置一条右转支路。右侧车道前方有一辆始终静止的L0车辆。事故发起车同样位于右侧车道，在接近停车车辆后向左临时变道，却在横跨车道线时与左侧车道正常行驶的L0车辆发生侧碰。两车碰撞后立即停止，车身分别占据右侧车道和左侧车道，封死全部通行空间。

首次碰撞发生时，后方车辆仍沿原方向继续行驶。距离最近的第三辆行驶中L0车辆因躲闪不及再次撞上事故车辆，并在碰撞后立即停车。第三辆L0之后的L1、L3与L5均同步前移，连续初始间距压缩为原来的40%。首次事故发生后，L1与L3先以−0.65m/s²同步轻微减速并拉开安全余量；待第三辆L0即将追撞时，L1以−8m/s²紧急制动，L3在下一时间步以−2.2m/s²缓慢制动，二者均不发生碰撞。L5初始位于上方车道，距路口约78米；事故发生后先保持上方车道并降速等待，确认L3完全刹停后继续接近路口，直至距路口约35米时再向下方车道变道，随后驶入右转支路绕开事故区域。

场景重点比较同一突发撞车事件下，不同自动驾驶等级因感知距离和决策能力不同而产生的应对差异。
