# 偶发事故场景

该场景使用视野清晰、路面正常的城市或园区道路，不包含雨雪、雾、积水、复杂交叉口和特殊外界障碍。

道路为单向双车道，前方包含轻微弯道，并在事故点前约40米处设置一条右转支路。右侧车道前方有一辆始终静止的L0车辆，距离事故点约14米。事故发起车同样位于右侧车道，在接近停车车辆后向左临时变道，却在横跨车道线时与左侧车道正常行驶的L0车辆发生侧碰。两车碰撞后立即停止，车身分别占据右侧车道和左侧车道，封死全部通行空间。

首次碰撞发生时，后方车辆仍沿原方向继续行驶。距离最近的第三辆行驶中L0车辆与前方事故车组的初始距离缩短至原来的约1/3，因躲闪不及再次撞上事故车辆，并在碰撞后立即停车。首次碰撞到第二次碰撞的间隔也由约4.15秒缩短至约1.35秒。第三辆L0之后的L1与L3同步前移，连续初始间距保持为原布局的40%。首次事故发生后，L1与L3先以−0.65m/s²轻微减速并拉开安全余量；待第三辆L0即将追撞时，L1以−8m/s²紧急制动，L3检测到L1真实急刹后以−1.75m/s²缓慢制动，二者均不发生碰撞。L5初始位于上方车道，相对上一布局继续向事故方向前移30米，初始距路口约50米。所有车辆先静止3秒，再从0直接切换到各自目标速度。L5直接切换到12m/s，事故发生、变道和右转期间均不改变速度。首次碰撞发生后，L5在接近路口时立即向下方车道变道，随后驶入右转支路绕开事故区域。

场景重点比较同一突发撞车事件下，不同自动驾驶等级因感知距离和决策能力不同而产生的应对差异。

现有L5车辆前后还布置了10辆背景车，分别为2辆L0、2辆L1、3辆L3和3辆L5。事故发生后，最前方背景L0仍以8m/s接近原有缓刹L3，在距离足够近时变入另一车道并停下；紧随其后的背景L1接近该L0后跟随变道，并停在L0后方。下一辆背景L3保持原车道停车。后方背景L0和L1从静止状态启动后以16m/s巡航。其中1辆L3在距弯道约20米时开始一次连续变道，变道完成后再制动，避免停车后继续偏转车身。4辆后方背景直行车仍以−6m/s²制动，其余3辆背景直行车继续以−1.5m/s²缓慢制动，最终两条车道形成4辆和3辆背景车的紧密队列且车身互不接触。

除道路最前方的2辆L5外，其余8辆L5不再集中在队尾。它们从第0秒起便分布在x=410米至x=180米的车队范围内，按下方车道4辆、上方车道4辆的比例穿插在L0、L1、L3车辆之间。各车位置根据相邻车辆速度和出口并线时刻预留安全间隙，避免L5阻挡16m/s的原有直行车辆。全部车辆静止展示3秒后，这8辆L5以12m/s巡航。下方车道车辆保持原车道，上方车道车辆从x=400米起降至8m/s并持续申请安全并线，在SUMO确认目标间隙可用后进入下方车道并恢复12m/s，随后全部驶入右转支路绕行。
