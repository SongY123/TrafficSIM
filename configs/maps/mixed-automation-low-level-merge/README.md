# 低智驾等级会车（L0-L3）

该场景沿用现有双向城市道路，不改变道路结构、车道数量、道路走向或交汇口位置。正向主路包含3条同向车道，按距离支路汇入口由近到远依次记为D1、D2、D3；下方约103米的单车道支路汇入D1；对向道路保留3条车道。场景共配置70辆L0-L3车辆，其中正向主路42辆、支路14辆、对向道路14辆。

仿真时长为30秒。0～10秒为稳定阶段，D1、D2、D3车辆以约15m/s的速度稳定直行，三条车道大体以1.2秒的间隔持续发车，在汇入开始前形成高密度但仍保留安全间距的车流。D2、D3分别保留一个自然的大车隙，避免车辆长期完全并排而无法安全变道。D3车隙前车略早发车、后车略晚发车，使低速D2候选车在当前和预测位置上都能保持安全距离。支路共配置14辆车，从第0秒起每2秒计划发出1辆，直到第26秒。当支路空间被前车占用时，SUMO会将待发车辆保留在车源队列中，因此最后一批车会在约29秒实际进入路网，让支路车源贯穿整个仿真。控制器不会对D1车流执行第10秒之前的脚本制动，也不会组织协同避让。

10～22秒为汇流扰动阶段。支路车辆进入距汇入口约23米的冲突区后先开始从14m/s减速，使其到达连接道时已经接近3.2m/s；D1仍然等到第10秒且支路确有车辆接近时才开始减速。D1减速目标约为1.5m/s，最多两辆满足安全间隙条件的D1车辆被动进入D2。D2在冲突开始约0.5秒后受到影响，目标速度约为6m/s；D3在约1.2秒后受到较轻影响，目标速度约为5.2m/s。由于D3延迟更久且减速度较小，实际车道均速仍保持D1最低、D2次之、D3最高。扰动的空间范围从D1向D2、D3逐步扩大，使更多接近汇入口的外侧车道车辆产生明显减速。D2向D3最多允许一辆安全候选车执行，真实运行中D1→D2和D2→D3都会出现，但不会为追求数量差异强制执行危险换道。D1进入D2前必须保留至少6.5米的纵向中心距离，D2进入D3需要9米。D3发车节奏保留一个自然大车隙，确保少量D2车辆能够安全进入。安全检查同时验证当前间距和按1秒换道时长预测的间距，避免高速候选车追上已经减速的目标车道车辆。车辆进入换道过程后按目标车道的较缓减速度运行，换道仍继续服从SUMO的碰撞规避。

22～30秒为恢复阶段。控制器停止发出明显变道请求，已完成变道的车辆保持当前车道。支路车源仍持续进入，同时解除中段的低速限制；主路各车道恢复约15m/s的巡航目标。SUMO的车辆加速度、跟车模型和安全检查继续生效，因此恢复从前车向后车自然传播，不会让整条车道同步瞬间加速。为了表现车源始终存在，30秒结束时支路和汇入口附近会保留尚未通过的安全队列。

整个场景不覆盖SUMO安全检查，不配置碰撞。支路连续车流保证汇流阶段始终存在真实的汇入需求。交通扰动只从汇入口附近开始，并以逐步扩大的范围向D2、D3传播，展示低智驾车辆在临近冲突后才进行跟车制动和被动变道的行为。
