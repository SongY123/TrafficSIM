# 低智驾等级会车（L0-L3）

该场景沿用现有双向城市道路，不改变道路结构、车道数量、道路走向或交汇口位置。画面最上方为3条对向车道，下方主路的3条同向车道按距离支路汇入口由近到远依次记为D1、D2、D3；下方约103米的单车道支路汇入D1。场景共配置155辆L0-L3车辆，其中下方正向主路42辆、支路14辆、上方对向道路99辆。

仿真时长为30秒。第0秒时，上方3条对向车道每条已有18辆车，共54辆车从地图最右侧一直错位铺到最左侧，覆盖约310米的完整道路。各车道使用不同的非等距位置，同一车道内车辆的初始速度互不相同，取值约为8.17～11.9m/s。后续45辆车统一从地图最右端，即全局横坐标x=320米持续进入。车源采用可复现的非固定刷新批次，每次随机表现为1辆、2辆或3辆新车，不再让三条车道每次都同步出现。控制器还会根据车道、智驾等级和车辆序号分配互不相同的巡航速度。最后一批在约第28.3秒发出，保证仿真全程上方三条车道都有车辆在运动。下方D1、D2、D3的42辆需求、发车位置和速度保持不变。支路的14辆需求也保持不变，从第0秒起每2秒计划发出1辆，直到第26秒。当支路空间被前车占用时，SUMO会将待发车辆保留在车源队列中，因此最后一批车会在约29秒实际进入路网，让支路车源也贯穿整个仿真。

10～22秒为汇流扰动阶段。支路车辆进入距汇入口约23米的冲突区后先开始从14m/s减速，使其到达连接道时已经接近3.2m/s；D1仍然等到第10秒且支路确有车辆接近时才开始减速。D1减速目标约为1.5m/s，最多两辆满足安全间隙条件的D1车辆被动进入D2。D2在冲突开始约0.5秒后受到影响，目标速度约为6m/s；D3在约1.2秒后受到较轻影响，目标速度约为5.2m/s。由于D3延迟更久且减速度较小，实际车道均速仍保持D1最低、D2次之、D3最高。扰动的空间范围从D1向D2、D3逐步扩大，使更多接近汇入口的外侧车道车辆产生明显减速。D2向D3最多允许一辆安全候选车执行，真实运行中D1→D2和D2→D3都会出现，但不会为追求数量差异强制执行危险换道。D1进入D2前必须保留至少7.5米的纵向中心距离，D2进入D3需要9米。D3发车节奏保留一个自然大车隙，确保少量D2车辆能够安全进入。安全检查同时验证当前间距和按1秒换道时长预测的间距，并计入换入车辆的制动位移，避免后车在换道过程中追上已经减速的候选车。SUMO在1秒内连续完成横向位移，并随轨迹输出先转向、后回正的车身角度，不再从一条车道瞬移到另一条车道。车辆进入换道过程后按目标车道的较缓减速度运行，换道仍继续服从SUMO的碰撞规避。

22～30秒为恢复阶段。控制器停止发出明显变道请求，已完成变道的车辆保持当前车道。支路车源仍持续进入，同时解除中段的低速限制；主路各车道恢复约15m/s的巡航目标。SUMO的车辆加速度、跟车模型和安全检查继续生效，因此恢复从前车向后车自然传播，不会让整条车道同步瞬间加速。为了表现车源始终存在，30秒结束时支路和汇入口附近会保留尚未通过的安全队列。

整个场景不配置碰撞。仅对首帧已校验为不重叠的54辆上方车辆关闭发车插入检查，进入仿真后的跟车与碰撞检查仍由SUMO负责。其他车辆仍使用SUMO默认发车安全检查。支路连续车流保证汇流阶段始终存在真实的汇入需求。交通扰动只从汇入口附近开始，并以逐步扩大的范围向D2、D3传播。
