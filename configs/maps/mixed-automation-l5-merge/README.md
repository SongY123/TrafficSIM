# L5会车

该场景与“低智驾等级会车（L0-L3）”使用完全相同的双向路网和约103米长汇入车道。20秒仿真共配置131辆车，其中L5为80辆、L4为34辆、L3为17辆。正向3条主车道共53辆，右侧汇入车道18辆，对向3条车道共60辆。

L5是主体车流，L3和L4采用与L5一致的协同汇流调度。第0秒时，正向主路D1、D2、D3分别铺设7辆、9辆和9辆车，车辆覆盖约100米的完整入口路段；三条对向车道各铺设12辆车，覆盖约200米路段。各车道使用可复现的非等距位置，初始车辆之间保持安全间隔。支路首帧已有6辆车，此后继续补充到18辆；正向主路和对向车道也持续补充车源。

主路D1与支路车辆的初始位置和后续发车时间预先错开，使车辆在汇合点以一主一支的顺序连续交替通过。真实SUMO验收中，18辆支路车均在20秒内完成汇入，汇入口形成37次连续交替通过。汇流车辆的稳定目标速度在15.8～16.2m/s之间，其他车道扩大到15.2～16.7m/s，以呈现自然的速度差异，同时避免明显制动和重新加速。

该策略不安排D1到D2或D2到D3的变道。控制器为每辆车提交稳定且可复现的差异化目标速度和车道锁定意图，SUMO继续负责安全跟驰、汇入裁决、车辆运动与到达状态。路线文件由`scripts/maps/generate_mixed_automation_l5_merge_routes.py`生成，重新生成后仍保持相同的密度、随机化布局和汇入节奏。
