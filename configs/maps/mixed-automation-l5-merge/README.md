# L5会车

该场景与“低智驾等级会车（L0-L3）”使用完全相同的双向路网和约103米长汇入车道。场景仍包含70辆L5车辆：正向3条主车道共36辆、右侧汇入车道4辆，以及对向3条车道共30辆。

全部车辆均为L5。系统在汇入车辆距离汇入口较近时，选择位于该车后方的0号主车道车辆进行短时协调减速，前车继续巡航，从而在汇合点前形成可用车隙。汇入口采用由该协作策略驱动的交替通行裁决，汇入车辆以稳定速度进入主路，完成汇入后恢复巡航；中间与最外侧车道保持稳定速度，避免低智驾场景中的速度波逐级扩散。

仿真开始时，0号主车道首车与匝道首车的纵向距离同样控制在约15米。L5车辆从初始阶段便协调这一紧凑空间关系，在接近汇合点前平稳调整速度并形成可用车隙。

该策略强调协同而非强制穿插。控制器只提交目标速度和车道锁定意图，SUMO继续负责安全跟驰、汇入裁决、车辆运动与到达状态。相同需求下，预期L5场景具有更高的正向到达数和平均速度。
