# L5会车

该场景与“低智驾等级会车（L0-L3）”使用完全相同的双向路网和约103米长汇入车道。场景包含70辆车，其中L5为50辆，L4和L3各10辆。正向3条主车道共36辆，右侧汇入车道4辆，对向3条车道共30辆。

L5是主体车流，L3和L4采用与L5一致的协同汇流调度。交汇侧主车道和支路车辆都以16m/s巡航，出发时序预先形成安全车隙。车辆在汇合点基本按一主一支的顺序交替通过，其中保留一组连续两辆支路车插入，用于体现高密度下的弹性调度。

主路与支路的初始位置和发车时间共同决定汇入次序，不再通过把单辆主路车从高速压到低速来临时让出空间。因此汇入前后没有明显的减速和加速波动。

该策略不安排D1到D2或D2到D3的变道。控制器只提交统一目标速度和车道锁定意图，SUMO继续负责安全跟驰、汇入裁决、车辆运动与到达状态。
